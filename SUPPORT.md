# Support

Spector.GPU is community-supported.

## Where to ask

- Use the **bug report** issue form for reproducible failures.
- Use the **feature request** issue form for proposals and use cases.
- Use the **security** process for vulnerabilities or sensitive reports.

Before opening an issue, search existing reports and try the latest release.

## Information to include

- Spector.GPU version and installation method
- Browser version, operating system, GPU, and driver
- Target framework or engine, such as Babylon.js, Three.js, or a custom renderer
- Minimal reproduction URL or repository when it is safe to share
- Relevant console errors and exact capture steps
- Whether the issue affects the extension, MCP server, or both

Do not attach proprietary captures, shaders, screenshots, access tokens, or private URLs without authorization.

## Compatibility expectations

WebGPU behavior varies across browsers, operating systems, adapters, and drivers. The project can investigate Spector.GPU behavior but cannot provide support for third-party engines, browser defects, or GPU drivers.
